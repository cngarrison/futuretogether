## Print Spec (for printer)

- **Bleed:** 3mm on all sides
- **Trim size:** A4 (210 × 297mm) for poster; A5 (148 × 210mm) for flyer
- **Bleed box (PDF size):** 216 × 303mm for A4; 154 × 216mm for A5
- **Trim marks:** At 3mm from each edge (corner crosses)
- **Colour:** RGB (browser-generated PDF) — suitable for digital/laser printing; not CMYK
- Tell printer: *"PDF is [bleed box size] with 3mm bleed on all sides. Trim to [trim size]. Trim marks at 3mm corners."*

---

## HTML → PDF Print Instructions (Chrome)

1. Open the HTML file in **Chrome** (not Safari)
2. `⌘P` → Save as PDF
3. Paper size: Custom → enter exact bleed box dimensions (e.g. 216mm × 303mm)
4. Margins: **None**
5. Scale: **100%** — do NOT fit to page
6. Background graphics: **✅ On** (essential — colours won't print without this)

## Voice Reminders for Copy

- Lead with human consequence, not technology name
- "AI" in subheadings/body — not in the main headline
- Never: doom framing without action counterpart
- Never: "prep", "survivalist", corporate speak
- Always: "you don't have to figure this out alone"
- Key phrases: "Not panic. Not paralysis. Action." / "The future is arriving. Let's face it together."
- Rural angle: fewer fallback options BUT stronger community bonds — frame as agency, not vulnerability
